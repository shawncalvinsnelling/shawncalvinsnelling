# How to Install This GitHub Profile README

GitHub profile READMEs work only when the repository name exactly matches your GitHub username.

## Step 1

Create a new repository named:

```text
shawncalvinsnelling
```

## Step 2

Set visibility:

```text
Public
```

A profile README normally needs to be public so people can see it on your GitHub profile.

## Step 3

Upload the `README.md` file from this folder.

## Step 4

Commit message:

```text
Add GitHub profile README
```

## Step 5

Go to:

```text
https://github.com/shawncalvinsnelling
```

Your profile README should appear at the top of your profile page.
